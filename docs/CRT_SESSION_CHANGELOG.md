# CRT Session Changelog

## 1.0.0 - 2026-07-16

- Added IANA/DST-safe, versioned session profiles.
- Added stable trading-day identity for midnight-crossing sessions.
- Added building, locked and expired session ranges with quality metadata.
- Added deterministic Asia->London and London->NY reversal/continuation models.
- Added session-bound PDH/PDL and previous-HTF sweep model detection.
- Added explainable 0-100 scoring and lifecycle states.
- Added separate local setup and lifecycle log namespaces.
- Added Session workspace with compact filters, evidence chain and range map.
- Added session-specific Gemini payload, schema and unknown-event rejection.
- Added DST, no-repaint, long/short symmetry and idempotency tests.
